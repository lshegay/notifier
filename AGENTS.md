# Инструкции для агентов

- Использовать **Bun** (runtime и менеджер пакетов: `bun`, `bun run`, `bun add` и т.д.).
- Использовать **TypeScript**.
- Использовать `type` вместо `interface` везде; ключевое слово `interface` использовать только для описания репозиториев.
- Учитывать правила форматирования кода из [.oxfmtrc.json](.oxfmtrc.json).
- Учитывать правила линтинга из [.oxlintrc.json](.oxlintrc.json).
